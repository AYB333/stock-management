# Stock Management App

A simplified stock management system designed for mobile use to help users manage products efficiently, with real-time synchronization and admin controls.

## Technologies Used:
- **Frontend**: React, Vite, Tailwind CSS
- **Backend**: Node.js (Express), PHP
- **Database**: Supabase (PostgreSQL)

## Features:
- Login and user management (Admin can manage accounts)
- Real-time product management (Add/Delete products)
- Product history (view deleted products)
- Search functionality
- Responsive design (optimized for mobile)

## Installation:

1. Clone the repository:
    ```bash
    git clone https://github.com/AYB333/stock-management.git
    ```
2. Navigate to the project folder:
    ```bash
    cd stock-management
    ```
3. Install dependencies:
    ```bash
    npm install
    ```
4. Run the development server:
    ```bash
    npm run dev
    ```
5. Open your browser and visit `http://localhost:5173/`

## Usage:

Once the app is running, you can:
- Log in as an Admin or User
- Admins can add or delete products
- View product history (who deleted what and when)
- Search products via the search bar
